# Schedula – Project Overview

## What is Schedula?

Schedula is a healthcare appointment scheduling platform designed to connect patients with doctors through a simple and organized booking system. The platform allows patients to discover doctors, check their availability, schedule appointments, and receive timely notifications. At the same time, doctors can manage their profiles, define available consultation slots, and efficiently handle appointment requests.

The primary objective of the system is to streamline the appointment booking process and improve communication between healthcare providers and patients.

---

## Core User Roles

### Patient

A patient can:

* Register and log in to the platform
* Browse available doctors
* View doctor profiles and availability
* Book appointments
* Reschedule or cancel appointments
* Receive appointment-related notifications

### Doctor

A doctor can:

* Register and create a professional profile
* Manage consultation availability
* View upcoming appointments
* Accept and manage patient bookings
* Receive appointment notifications

### Admin (Future Scope)

An administrator may be responsible for:

* Managing platform users
* Monitoring appointments
* Handling system-level operations
* Ensuring platform integrity

---

## Key Workflows

### Patient Workflow

Register → Login → Browse Doctors → Select Available Slot → Book Appointment → Receive Confirmation → Manage Appointment → Receive Notifications

### Doctor Workflow

Register → Complete Profile → Set Availability → Receive Appointment Requests → Manage Schedule → Receive Notifications
